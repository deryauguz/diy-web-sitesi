DIY Web Sitesi

Kullanıcıların sahip oldukları malzemeleri seçerek bu malzemelerle yapılabilecek DIY (Do It Yourself) projelerini keşfetmesini sağlayan PHP ve MySQL tabanlı web uygulaması.

Proje Hakkında

Bu proje, kullanıcıların evlerinde bulunan veya kullanmak istedikleri malzemeleri seçerek uygun DIY projelerini görüntüleyebilmelerini amaçlamaktadır.

Sistem üzerinde kullanıcılar:

Kayıt olabilir ve giriş yapabilir.

Kullanabilecekleri malzemeleri seçebilir.

Seçilen malzemelere uygun DIY projelerini görüntüleyebilir.

Projelerin içeriklerini ve gerekli malzemelerini inceleyebilir.

Hesaplarından çıkış yapabilir.

Projenin temel amacı, kullanıcıların mevcut malzemelerini değerlendirerek yaratıcı ve uygulanabilir proje fikirlerine kolayca ulaşabilmelerini sağlamaktır.
